## Resumo curto

Este chunk trata principalmente de regras para tratamento de dados pelo poder público, publicidade das operações, compartilhamento de dados e responsabilidades. Para Zuno, é menos central no MVP privado, mas pode ser relevante se houver parcerias públicas, escola pública, convênios, pesquisa, bolsas ou integração com órgão público.

## Pontos importantes para o SaaS

- O poder público deve tratar dados para finalidade pública e informar hipóteses, previsão legal, finalidade, procedimentos e práticas.
- Uso compartilhado pelo poder público deve atender finalidades específicas e respeitar princípios da LGPD.
- Transferência de dados públicos para entidades privadas é restrita a hipóteses previstas.
- A autoridade nacional pode solicitar informações e relatórios de impacto.
- Órgãos públicos podem receber recomendações para cessar violações.

## Implicações técnicas

- Se houver convênio com órgão público, escola pública ou programa governamental, revisar regras específicas.
- Evitar receber bases públicas de alunos sem contrato, finalidade e base legal claras.
- Registrar origem, finalidade e escopo de qualquer dado vindo de órgão público.
- Separar dados de projetos públicos de dados comerciais/privados quando aplicável.

## Pendências ou decisões humanas

- Definir se Zuno terá clientes públicos no futuro.
- Criar regra para contratos com escolas, prefeituras ou órgãos públicos antes de aceitar dados massivos.
- Avaliar necessidade de relatório de impacto em projetos públicos.
