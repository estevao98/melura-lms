# ADR-0001: Obsolete Live-Video Launch Path

## Status

Obsolete. Replaced by `ADR-0002-google-meet-only-live-flow.md`.

## Historical Note

This ADR previously documented an alternative live-video launch path. It is no
longer product direction and must not be used to plan or implement Melura live
classes.

The accepted decision is that Melura MVP uses Google Meet external links only.
Current live-class behavior is documented in
`docs/decisions/ADR-0002-google-meet-only-live-flow.md`.
